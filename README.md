# Sparse PCA — a study track

A five-part illustrated walkthrough that builds up, from first principles, to the
**branch-and-bound algorithm for Sparse PCA** of Berk & Bertsimas (2019),
*Certifiably optimal sparse principal component analysis*.

The material was written as a self-study track: each concept is introduced before it is needed,
with figures generated programmatically and mathematics typeset with MathJax. The written
content is in **Portuguese**.

**Start at [`index.html`](index.html)** — it is the table of contents and links the parts in order.

## The track

| Part | Page | What it covers |
|---|---|---|
| — | `index.html` | Table of contents and reading order |
| 1 | `01_pca_classico.html` | Classical PCA from the ground up: covariance, change of basis, the best-projection argument, the eigenvector characterisation, SVD, and a worked 4D→2D example ending in the limitation that motivates sparsity |
| 2 | `02_sparse_pca_o_problema.html` | The sparse PCA problem: the ℓ₀ norm, why the problem is NP-hard, convex relaxation and the Lasso analogy, and the geometry that makes it hard |
| 3 | `03_primitivas_espectrais_power_method.html` | Spectral primitives: the power method, Rayleigh quotient iteration, and truncation |
| 4 | `04_branch_and_bound_sparse_pca.html` | Branch-and-bound for Optimal-SPCA: the search tree, five bounds, pruning, and the optimality gap |
| 5 | `05_deflacao_variancia_qr.html` | Deflation, cumulative explained variance via QR, and the 70% criterion |

## Figures

Every figure is generated by a Python script in [`_tools/`](_tools/) rather than drawn by hand, so
each one can be regenerated and adjusted. `_tools/al_template.py` holds the shared CSS and the
`build()` / `embed()` / `integrity()` helpers used to assemble the pages; images are embedded
directly into the HTML, which is why the files are large and fully self-contained — a page can be
opened offline with no assets folder.
